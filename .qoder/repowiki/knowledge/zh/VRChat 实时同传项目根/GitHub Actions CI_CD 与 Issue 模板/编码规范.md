- 跨平台差异通过分 job 隔离：Windows 与 Linux 各自拥有独立的 runs-on、依赖安装与步骤，避免在同一 job 里混用平台命令。
- 重复的构建流程抽成可复用 workflow（appimage.yml），由 ci.yml 与 release.yml 通过 `uses:` 引用，确保系统依赖清单与构建顺序只写一处。
- 关键门禁以显式断言实现：导入 Windows 独占依赖 (`openvr`, `pyaudiowpatch`)、产物体积下限 (exe ≥20MB、AppImage ≥30MB)、平台纯度 (`check_platform_purity.py`)、tag 与 `__version__` 一致性。
- 所有 shell step 都设置 `PYTHONUTF8=1`，并在注释中记录踩坑原因，作为 UTF-8 输出的统一约定。
- 对可能卡死的 job 统一设置 `timeout-minutes: 30`，防止旧 PR 长期占用 runner。
- artifact 上传/下载使用带 major 号的 action 版本（如 `upload-artifact@v4` 与 `download-artifact@v4` 配对），并在注释中强调升级时必须两处同步修改。
