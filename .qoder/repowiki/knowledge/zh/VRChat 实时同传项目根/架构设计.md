根目录作为项目入口，将三个子模块按职责切分：server（Cloudflare Worker + Durable Object 的房间 WebSocket 中继）、github_ci（CI/AppImage 构建与 Release 发布）以及未展开的桌面客户端代码。
- 跨子模块的耦合点集中在 `config.example.yaml`：它定义了 session/capture/directions/chatbox/overlay/output/text_input/room/ui 等完整配置 schema，server 与桌面客户端都基于同一份语义解析，保证「Windows 与 Linux 共用同一份 config.yaml」。
- 运行时通过 `room.server_url` 指向 server 部署地址，形成「客户端 → Cloudflare 房间中继」的双端架构；其余功能（chatbox OSC、SteamVR/OpenXR overlay、虚拟声卡、TTS）仅在客户端侧运行。
- 文档层在 `docs/` 下提供多语言 README/GUIDE 及实测记录，README.md 作为总入口链接到各平台指南。
