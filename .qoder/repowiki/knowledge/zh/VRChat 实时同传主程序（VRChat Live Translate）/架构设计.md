仓库由三部分组成：
- Python 主程序 `vlt/`：顶层脚本 `run_gui.py` / `run_chatbox.bat` / `run_overlay.sh` 等作为 PyInstaller 入口，统一兜底 `sys.stdout/stderr` 并拦截 `--verify-*` 自检参数；核心包 `vlt/__init__.py` 声明三层架构——采集(capture) → 会话(session) → 输出(output)，模型差异收敛在 `session/` 内。
- 内部子包分层：`platform/` 封装 Windows(WASAPI)/Linux(alsa/pulse) 音频与 overlay（SteamVR/OpenXR/X11/Wayland）平台差异；`room/` 实现多人房间 WebSocket 协议、客户端、发布器与 sink；`session/qwen38.py` 对接千问云实时流；`gui_*` 系列文件按 Tkinter 界面职责拆分（引擎、代理、聊天、设置、主题、布局等），通过 `ui_state.py` / `ui_text.py` 共享状态与 i18n。
- Node.js 中继服务 `server/`：基于 Cloudflare Workers + Durable Object (`wrangler.toml`) 提供房间文本广播，Python 端通过 `websockets` 连接。
- 测试与验证：`tests/` 下按功能域组织 pytest 用例，`scripts/verify/` 为独立验收脚本集，`scripts/build_appimage.sh`、`scripts/build_exe.py`、`gen_buildinfo.py` 负责构建产物。
